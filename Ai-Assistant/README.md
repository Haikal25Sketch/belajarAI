# AI Assistant

Personal AI Assistant dengan RAG + Function Calling.

## Fitur
- Cari informasi dari database pribadi (RAG)
- Kalkulator
- Cek cuaca
- Memori percakapan

## Setup
1. Clone repo
2. pip install -r requirements.txt
3. Copy .env.example ke .env dan isi API key
4. Tambah pengetahuan di pengetahuan.txt
5. python main.py
